# Correspondence Guide: Branch (c) Elimination

This guide maps each proof element in the branch-(c) paper to its Lean 4
formalization and computational verification scripts. It follows the format of
`branches_a_b/correspondence_guide/CORRESPONDENCE_GUIDE.md`.

**Source freeze.** All Lean sources below live in the frozen v3.1 bundle:
`JC2D-branches_a_b_c_unified/branch_c/bundle_v3_1/jacobian_lean/Jacobian/BranchC/`.
The bundle is byte-identical to the v3.1 release (manifest verifies); cite it,
not working copies.

**Paper.** `JC2D-branches_a_b_c_unified/branch_c/paper/branch_c_elimination.pdf`
(18 pp, 2026-10-01).

## Paper Structure → Lean → Scripts

### Introduction, Main result, Logical status (§1)
- **Lean**: `main_theorem_c_of_chartEmpty_T1ne0` in `T1Zero/Combine.lean`
- **Statement**: `ChartEmptyC_T1ne0 L → ¬∃ P Q λ, λ ≠ 0 ∧ NewtonNFc P Q ∧ [P,Q] = λx²`, over any characteristic-zero field L, with no `sorry` and only the standard axioms (`propext`, `Classical.choice`, `Quot.sound`).
- **Logical status**: Branch (c) is closed **under the computational premises of §5.9** (grade B, outside Lean). Not closed by Lean alone.

### Source data (§2)
- **Source-gating**: All base objects verified against GGHV v1, Proposition 4.3, case (1). The pipeline's generators were found to certify a differently parametrized ideal than `lower_c`'s; step 1 was redone for `lower_c` (`chart_certificates/step1/`, `logs/run_step1.log`).

### The polynomial system (§3)
- **Scripts**: `chart_certificates/step1/certB_lowerc.py` (exact over K₅, t₁ = 0 slice), `modp_chart.py` (𝔽₁₀₁, 𝔽₁₀₀₀₀₀₃, 𝔽_{109⁵}).
- **Checkers**: `check_certB_lowerc.py` (independent FLINT substitution), `check_modp_chart.py` (random evaluation). Controls: perturbed coefficient, Θ₃ dropped, wrong w — all rejected.

### Exact layer reduction (§4)
- **Lean**: `Descent2R/` — `L4` (54 modules), `L3` (57), `L2c` (57), `L1` (60), `L0` (60), `Lm1` (99), `Lm2` (110), plus `Facts`, `Vals_*`, `Main`, `Bridge` (9). Generated by `certgen_c/gen_refl_c.py` (chain) and `certgen_c/gen_bridge_c.py` (Bridge); every identity pre-checked in Python by exact integer arithmetic.
- **Main theorem**: `chart_descent_refl` in `Descent2R/Main.lean` — 752 `have`s, 231 via `cancel_int`; conclusion is the twelve conjuncts `cond_Omega w … = 0 ∧ … ∧ cond_Em2pure_17_37 w … = 0`.
- **Grade**: A (kernel reflection; built; axioms audited).

### Normalization (§5)
- **Lean**: `Descent2R/Bridge.lean` — extracts the 132 raw equations exactly as written; defines `ChartEmptyC`.

### The top layer (§6)
- **Lean**: `CondsC.lean` — the twelve conditions `cond_Omega … cond_Theta3`.

### Descent (§7)
- **Lean**: `chart_descent_refl` (see §4). Hypotheses: `w` with `R(w) = 0` (i.e. `w^5 - w^4 + 3w^3 + 3w^2 + 26 = 0`), the 19 top-layer K₅ values, the 123 unknowns, the 132 raw equations.

### The chart conditions (§8)
- **Lean**: `ChartEmptyC` (`Descent2R/Bridge.lean`, `T1Zero/Combine.lean`) — the twelve conditions have no common zero with `R(w) = 0`, `b₁₂,₂₂ = 1`.

### The stratum b₁₁,₂₀ = 0 (§9)
- **Lean**: `chartEmpty_t1_zero` in `T1Zero/Main.lean` — kernel-checked.
- **Negative controls**: `diag/t1z_controls.py` → `logs/t1z_controls.log`: 5 controls (C1–C5) all **fail as required**.
- **Grade**: A.

### The whole chart (§10)
- **Outside Lean (grade B)**: the rank lemma + exact finite-field ranks at two primes (1000003, 32003), two implementations (FLINT `nmod_mat`, numpy elimination), exact input checks — `chart_certificates/step3b_rank_lift.py`, `step3b_rank_lift.log`.
- **Rank-lemma premises (§5.9)** → `branch_c/rank_lemma_check/`: 6398 packed natural-number identities (`C·M_S ≡ I` mod 32003 for the W = 24 pivot block), kernel-checked with axioms `[propext]` only; 5 negative controls rejected, 1 pass control accepted; generators matched exactly to the Lean `cond_*` (parsed from `CondsC.lean`); R irreducible (FLINT + mod-67 + degree patterns).
- **What Lean does NOT check**: the link from the pivot-block arithmetic to `ChartEmptyC_T1ne0` (plan A1–A5, deferred).

### Proof of the main theorem (§11)
- **Lean**: `T1Zero/Combine.lean` —

  - `main_theorem_c_of_chartEmpty_T1ne0`: the top-level theorem.
- **Grade**: A for the implications; the remaining premise `ChartEmptyC_T1ne0` is grade B (outside Lean).

### Epistemic status (§12)
- Grades A/B/C per claim; see the claim registry (GUIDE.md §8, IDs C1–C11).

## What is proved in Lean vs. outside Lean

- **In Lean (grade A)**: statements 1–4; the 6398 pivot-block identities (C9, arithmetic only); the Muse `reduction_lemma` refutation (C7).
- **Outside Lean (grade B)**: statement 5 (`ChartEmptyC`/`ChartEmptyC_T1ne0`) — the rank lemma with two-prime, two-implementation ranks, exact input checks, and controls; the meaning of the 6398 identities (C9-meaning); generator-to-`cond_*` matching (C10); R irreducible (C11).

- Not a review of the Muse bundle (withdrawn) or the p-adic argument (closed as not needed).
